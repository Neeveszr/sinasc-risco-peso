# frontend — Aplicação web

Responsável: Antonio.

## Telas mínimas

| Tela | Conteúdo mínimo |
|------|-----------------|
| Login | Acesso com dois perfis: operador e gestor/auditor |
| Predição | Formulário com os dados do caso e validação das entradas |
| Resultado | Faixa de risco em linguagem do usuário, principais fatores, aviso de que é apoio à decisão e botão "Solicitar revisão humana" |
| Auditoria (gestor) | Histórico das predições com filtros por período, usuário e faixa de risco, e indicação dos pedidos de revisão |
| Transparência | Versão do model card voltada ao usuário: dados usados, métricas principais e limitações |
| Privacidade | Quais dados são coletados, finalidade, tempo de guarda e quem acessa |
